## 📌 Project Overview
**SUQMS (Smart University Queue Management System)** is a Python-based queue management application designed to streamline student service workflows across university departments (e.g., ICT Center, Bursary, Admissions, and Faculty Offices). 

The system handles real-time ticket generation, priority queue processing, service status updates, and student queue withdrawals, eliminating manual crowd overcrowding and reducing waiting times.
